Doc Validator
=============

Проект за валидация на документи (фактура, доклад и заявка
за материали), реализиран на Python с два шаблона за дизайн —
**Chain of Responsibility** и **Visitor**.

Проектът включва:

- CLI входна точка (``main.py``);
- HTTP сървър на Flask с браузърна форма и JSON API;
- Docker контейнер за лесен деплой;
- документация, генерирана с Sphinx, PlantUML и docxbuilder.
